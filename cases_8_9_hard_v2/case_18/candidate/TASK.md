# 第9题 / Case18：会议发布版的定向去标识化（正式困难版）

将 input/programme.mp4 制作为可发布的匿名版本：只处理 target_B.jpg 中的 B。她在源录音中自称 Francina，本题添加的化名为“林岚”。遮住她在所有主画面、画中画和回放中的脸及姓名条；完全去掉她的声音，同时保留别人和主持人的非姓名内容；字幕保留她的设计观点，身份统一替换为“受访者B”。封面、字幕、容器元数据和交付说明都必须一并处理。“林岚研究所”是题方虚构机构，与此人无关，必须保留。

成片为300秒、25fps、704×640。禁止删帧、改速、裁掉画面、整段静音或遮住整个人所在的机位。使用不透明深灰遮罩；不接受只改音高、轻度模糊或像素化。所有非目标人脸与文字、原有画面顺序和其他人的语音须保留。允许遮罩覆盖头发边缘，但不能以大块遮挡代替跟踪。

请按 OUTPUT_CONTRACT.md 交付最终 MP4、音频、逐帧遮罩、字幕、匿名封面、可重建工程和编辑记录。提供的 tools/render.py 只负责把你选择的遮罩、音频和字幕重建为成片，不会自动识别目标或替你作匿名决策。

## 输入与素材性质

- programme.mp4：唯一画面时间轴，7500帧；动态轮换布局、主画面放大、重复画中画和回放。
- track_A/B/C/D.wav：从真实 AMI 录音选出的片段，按题方剪辑时间线分轨排列；host.wav 为明确披露的中文系统合成主持声；mix.wav 为它们的整数PCM求和。
- edit_map.json：剪辑时间与原始素材时间映射；用于工程审计。音轨字母与人物角色一致，不随屏幕位置变更。
- subtitle_cues.json / zh_source.srt：题方人工整理的中文译稿。保留观点、金额、否定与说话人归属；这是提供给解题者的待编辑材料，不是匿名答案。
- cover.png：源视频首帧封面；target_B.jpg 为真实原图身份参照。

本片是**明确构造的多轨编辑测试**，不是原始连续会议：真实人物与真实录音来自同一次会议；画面轨道可来自不同原始时刻，未被选入音频的画面可能仍出现口部动作；重叠发言是将无他人标注发言的原录音片段组合而成，部分 B 发言会回放。参与者声音没有克隆或合成。原始头戴麦克风存在串音，本题不把它们冒充已经完美分离的原生干净声源。任务范围是对**给定发布剪辑**进行定向处理，不推断真实会议因果顺序。

## 公开验收口径（100分）

机器80分：逐帧目标脸/姓名遮罩25、非目标脸与遮罩范围15、实际成片与工程一致及封面15、声音定向删除与保留20、字幕和元数据5。原生音视频裁判20分：剩余可识别身份8、重叠语音和语义保留8、观看可用性4。

所有技术硬条件必须通过，原生裁判门槛必须通过，总分至少80。每一帧检查，不能以平均遮挡率掩盖短暂露脸。核心脸部矩形为检测辅助后经题方抽查的保守区域；每帧覆盖≥99.5%，非目标脸受遮挡≤0.5%；允许的目标脸周边和姓名带以外额外遮罩≤允许区域面积1%。原始媒体若反证真值，裁判应标记待复核，不按错误标注强扣。

音频以分轨建立样本级可验证基线：去掉 B，主持人仅人名发声区间允许静音并向两侧最多扩展80ms；其他声音保留。不能因为 B 与别人重叠就一起静音。逐样本误差阈值和成片重建容差见 OUTPUT_CONTRACT.md。隐藏逐帧区域、姓名精确发声边界及裁判提示不会随候选题包提供。

可用 Python、OpenCV、FFmpeg；专业编辑器可选 DaVinci Resolve、Premiere Pro、REAPER，但最终须导出本题可审计格式。提供 API 后才执行独立原生看听裁判；本题包不预先声称某模型能得多少分。
