# Case 31 (hard v2) — 四人会议字幕对轴：交付说明

## 交付物
| 文件 | 内容 |
|---|---|

| `interview.srt` | 183 条 cue；按 ASS 全部事件边界切成互不重叠时间单元，每行 `X: ...`，持续文本跨相邻单元保留 |

101 个文本组（U001—U101）全部被映射覆盖；ASS 词元与逐词稿精确匹配（738/738，precision 1.000 / recall 1.000）。
每个 U 组独立成事件（长组按 ≤2 行 × ≤41 字符拆成多事件），因此重复的相同短句保留为独立 ASS 事件、并在 SRT 对应边界另起新 cue。

## 方法（无外部网络、无私有真值）
1. **时间轴**：`transcribe`/faster-whisper small int8 CPU（`scripts/pipe.py`，`whisper_full.json`）取词级时间戳，作为唯一精确时轴。
2. **说话人结构**：把 4 段声音参考（各 2 s）拼在 9 个 ≤30 s 片段前，交给本地 Qwen 音频代理做“参考+听写+重叠标注”（`clip*.wav` → `q*.json`）。
3. **对齐**：Qwen 语句按词元模糊匹配独占绑定到 whisper 词流；未命中的语句（多为被主话轮盖住的附和）在其前后已锚定语句之间按序插值，形成合并词流（whisper 精确时间 + Qwen 声线标签）。
4. **检索定位**：101 个乱序文本组在该合并词流上做滑窗模糊匹配（0.78×覆盖率 + 0.22×密度 − 重用惩罚），长组优先、已占用位置扣分，使附和落到不同位置。93/101 覆盖率 =1.00，其余为 1—3 词碎句（覆盖率 0.42—0.67）。
5. **分句/换行**：每组文本按 ≤2 行 × ≤41 字符（含 `X: ` 前缀）自动折行，超长组按时例切成多事件；时长下限 0.40 s、上限 6.0 s、读速 ≤24 字符/秒；任何事件不跨 `edit_boundaries`（0 / 93.52 / 170.76）。
6. **版面**：PlayRes 704×576，YaHei 18 px，`Alignment=2`，MarginV = A:3 / B:48 / C:93 / D:138。实测两行块最上行 y≈399 ≥ 392（底部 32% 区），最下行 569 ≤ 575；顶部 68% 原画面未被覆盖。
7. **说话人身份**：以第 2 步（听写时同步判定）的字母为准，另按内容链手工校正 14 组（预算陈述 U014/U016/U017/U058→A；主持人收束 U008/U030/U031/U068/U071/U078/U086/U093/U094/U097→C）。

## 已知不足（诚实记录）
- 为校验声线又做了两组独立实验：16 段 2.2 s 探针识别（`pr0/1.json`）与 9 段“逐行判人”复检（`d*.json`）。三者两两一致率仅 24—30%（≈随机），说明该 Qwen 声线映射在跨请求间不稳定；故只采用第一次听写的结果 + 内容链校正，**角色标签是本交付最不可靠的部分**。
- 15 个 1—3 词碎句（U003/U005/U012/U015/U031/U034/U039/U041/U044/U062/U069/U074/U079/U080/U081）时轴为弱匹配或就近挂靠，误差可能 >500 ms；其中 U074「Oops」在 whisper/Qwen 两路都没听到，是按词形相似度挂到 U091 附近的。
- 读速约束仍有 27/122 个事件超过 24 字符/秒：这些事件落在同一说话人的密集簇里，前后都没有可延展的空档（延展会制造同角色重叠，优先级更低）。已按“同角色不遮字 > 读速”取舍，后续若加时长预算应先重排附和的落点而不是压缩文字。
- 碰撞簇时轴被规整化：最终版对同角色重叠做了后处理（在前后空闲窗口内等距重排），当前 122 事件同角色重叠为 0，但被重排的少数极短事件时轴精度下降。
- 未使用 `tutorial.mp4`/`aegisub_manual.html` 之外的软件功能；无鼠标操作，全部脚本生成。

## 依赖与复现
渲染/重建只需 `python3`（标准库）+ `ffmpeg`（libass、libx264、aac 透传）；中文字包无关，字体用系统 Microsoft YaHei（`fc-list` 可见）。
`scripts/pipe.py`（whisper+Qwen 融合词流）→ `scripts/gen.py`（文本组定位）→ `scripts/final.py`（说话人+事件切分）→ `scripts/write_out.py`（ASS/SRT/alignment）。
中间件 `whisper_full.json`、`q*.json`、`clips.json`、`anchors.json` 留在 `/workspace/scratch`（非提交项）；本提交不含源视频副本、不含模型文件。TTS 兼容层本次**未使用**（题目不要求配音，且原声必须保持不变）。
