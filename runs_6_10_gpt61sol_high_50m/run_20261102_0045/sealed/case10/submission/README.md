# 中文音频描述修订交付

课程素材署名：omniALE 原创受控注意力课程（题包说明为 CC BY 4.0）。本交付保留 v2 原课程的全部原帧、帧序和教师原始 PCM 样本。新增描述采用本机中文系统 TTS，正常速率生成，仅裁去首尾多余静音，没有变速、删教师、压低教师或改绘画面。来源详情请参见题包 SOURCES.md。

## 播放

`accessible.mp4` 是可直接播放的完整描述版：960×540、25fps、185 秒，含一条视频、一条教师与描述混音，以及一条可选的中文描述字幕。十条描述录音在 `clips/`；`description.wav` 是独立描述轨，`teacher_mapped.wav` 是保留全部教师样本的映射轨，两者均为 48kHz、单声道、16 位 PCM。

使用题包提供的播放器，可在两版之间保持源课程进度切换。运行：

```bash
python3 /work/candidate/tools/serve.py --submission /work/submission --port 8766
```

在支持 MP4 的浏览器打开 `http://127.0.0.1:8766/player.html`。关闭描述播放原始 180 秒课程；开启后播放 185 秒描述版。使用“六个阶段”按钮跳转；“从头播放”用于主动重听。播放器和状态机使用题包提供的原文件，不需要向 submission 添加网页或脚本。

## 修订内容

对照新旧两版实际视频及原教师轨，描述按以下八处视觉变化重写：

1. 词元从纵向排列改为从左到右的小猫、追逐、红球。
2. 颜色明确对应蓝色小猫、绿色追逐、橙色红球，不再把蓝框认作红球。
3. 每行的三列改为值、查询、键。
4. 红球查询对应的三个分数按小猫、追逐、红球的顺序逐个出现。
5. 遮罩阶段先查看追逐查询，随后切换为红球查询；追逐不能读取未来的红球，红球能够读取三个位置及自身。
6. 加权的值信息由右向左流入汇聚框。
7. 线宽表示权重大小：追逐最粗，红球最细。
8. 四个模块按值汇聚、输出映射、加入原始表示、更新表示的顺序亮起。

仍保留四组有用信息：同一行的三种向量属于同一个词元；第三阶段的当前查询是红球且原始分数为一、二、零；三个归一化权重为零点二四五、零点六六五、零点零九；汇聚结果经过输出映射后再与原始表示相加。另补读了三个值向量及加权结果零点三三五、零点七五五，没有编造最终表示的数值。教师已清楚讲出的概念不另作冗长复述。

## 时间、字幕与导航

十条描述分布于全部六阶段，单条文字与实际录音一致；数字逐字读出。描述主要利用教师停顿，允许在同一阶段末尾回顾刚才的变化。仅在源 150 秒处加入五秒冻结，输出 150–155 秒重复源 149.96 秒的帧，随后恢复源 150 秒原帧。该暂停属于第五阶段。

| 阶段 | 标题 | 源起点（秒） | 描述版起点（秒） |
|---|---|---:|---:|
| P1 | 词元与身份 | 0 | 0 |
| P2 | 查询、键和值 | 25 | 25 |
| P3 | 原始分数 | 55 | 55 |
| P4 | 因果遮罩 | 85 | 85 |
| P5 | 加权传递 | 115 | 115 |
| P6 | 更新表示 | 150 | 155 |

`descriptions.json` 为逐条实际读音和采样准确的起止时间；`description.vtt` 由其生成并内嵌到 MP4。导航在暂停后的教学阶段起点定位，P6 不会进入 P5 的冻结暂停。暂停内开关的续接行为由题包原播放器的暂停游标状态机处理。

## 重建与检查

`project.json` 固定声明渲染器、各数据文件及两个源素材的 SHA256。保留题包路径后，可用公开渲染器重新生成成片和三项派生音轨／字幕：

```bash
python3 /work/candidate/tools/render.py --submission /work/submission
```

本次制作调用同一公开渲染器，仅将临时文件目录定向至 `/work/scratch`；帧映射、PCM 混音、编码和封装参数均使用原实现。逐条录音是可重建工程的实际输入，不依赖再次合成 TTS。

实际媒体自检结果：

- 教师映射轨与原始 PCM 插零后的结果逐样本相同；描述轨与逐条 WAV 求和结果逐样本相同。
- 十条描述与教师的保守发声区间交集均为零；逐条实际发声语速最高约 4.397 字／秒，滚动十秒按有效发声分配的字数最高约 35.709。
- 全部 4625 帧逐帧比较通过；最大单帧平均绝对误差约 1.968/255，任一通道偏差超过 32 的像素占比最大约 0.0320%。帧时间戳符合 25fps。
- 最终 AAC 解码音轨与同参数参考编码的峰值误差为零，均方根误差为零。
- 外部 VTT 与 JSON 同文同时间；内嵌字幕提取后核对文本与时间通过；MP4 轨道数量、采样率、分辨率和时长通过。
- 六章节起点及源哈希核对通过。HTTP 下播放器、配置、导航、字幕加载正常，两版 MP4 的字节范围请求均返回正确的部分内容响应。此项是资源服务检查，不代替真实浏览器交互测试。

过程脚本、提帧和检查缓存均留在 `/work/scratch`，不属于交付。
