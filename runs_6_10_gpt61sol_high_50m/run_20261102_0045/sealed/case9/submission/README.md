# 会议发布匿名版

本交付只针对受访者B进行定向去标识化。成片保持原有300秒时间轴、704×640画幅、25fps和7500帧，未删帧、变速或裁切。分屏和两类画中画中的B面部逐帧以RGB(16,16,16)不透明遮罩覆盖，姓名条同时覆盖；其他参与者及原有画面顺序保留。

音频由A、C、D三轨与处理后的主持轨作整数PCM求和，B整轨不进入混音。主持轨仅删除三处个人姓名的实际发声样本，其他内容和机构名称片段完整保留；重叠发言中的其他人不会随B一并静音。B的观点仍由字幕表达，两处身份自述统一使用“受访者B”，其他说话人的文字、金额、否定、未完成句和说话人归属保留。

## 文件及使用

- `anonymous.mp4`：最终发布文件，含一条视频、一条音频和一条中文字幕轨；播放器中可选择中文字幕。
- `final_audio.wav`：16000Hz、单声道、16位PCM，共4,800,000采样。
- `mask.mkv`：7500帧FFV1无损灰度二值遮罩；白色替换为深灰，黑色保留源画面，无音轨。
- `subtitles.json`、`zh.srt`：匿名字幕及渲染器生成的重叠合并字幕。
- `cover.png`：按第一帧遮罩处理的无损封面。
- `project.json`：固定结构的可重建工程，绑定源视频SHA256。
- `edits.json`：匿名编辑决策、处理区间与实测自检记录。

在原题包仍位于当前目录结构时，可用题方公共渲染器重建。该命令会覆盖成片、SRT及封面：

```bash
python3 /work/candidate/tools/render.py --submission /work/submission --source /work/candidate/input/programme.mp4
```

重建需要原题包源视频、Python、NumPy、OpenCV和FFmpeg。工程不执行提交者代码，逐帧决策已固化在遮罩中。

## 核对与局限

已对全部7500帧核对遮罩值、尺寸、顺序、重建画面与成片的编码误差，并单独核对可见目标脸实例和非目标脸所在区域。封面与源首帧应用遮罩后的像素完全相同。字幕结构、顺序、ID、时间及说话人字段逐项核对，SRT与公共渲染器生成结果一致。音频相对于定向删除后的整数分轨基线逐样本误差为零；成片AAC也与相同参数重编码的参考音频逐样本一致。详细数值见`edits.json`。

面部跟踪采用检测辅助逐帧定位、短时运动包络与转头段复核；面部周围保留少量遮罩边缘以防压缩边缘漏出。素材固有的低清晰度、剪辑停顿和麦克风串音条件保留，未对其他人的声音重新降噪或重建。B的声音删除后，部分时段只显示其观点字幕。上述是对公开素材的本地核对结果，不代表隐藏标注结果或独立语义裁判评分。
