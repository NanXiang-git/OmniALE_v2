# 消失的纸牌：最终评分方案

最终分 = 视觉理解分 V × 口述影像有效交付系数 C，再执行已确认失败的硬门槛封顶。满分100分。

## 视觉理解分 V

| 指标 | 满分 | 评价内容 |
|---|---:|---|
| 关键视觉事实 | 45 | 人物、动作、纸牌位置与关键可见事件是否准确，有无重要遗漏或编造 |
| 纸牌状态与转移关系 | 35 | 持牌者、藏牌位置及转移前后关系是否连续、清楚、正确 |
| 信息揭示时机 | 5 | 是否提前透露尚未出现的关键视觉信息 |
| 描述及时性 | 15 | 重要信息是否在听众仍能用于理解当前事件的时间内说出 |
| 合计 | 100 | |

## 口述影像有效交付系数 C

| 构成小项 | 内部满分 | 评价内容 |
|---|---:|---|
| 对白避让 | 5 | 旁白是否合理避开原片对白 |
| 对白可懂度 | 10 | 加入旁白后原对白是否仍可听清 |
| 关键音效保护 | 10 | 理解剧情所需的音效是否受到遮蔽 |
| 混音数值规格 | 5 | 响度、峰值等是否符合要求 |
| 指代与信息效率 | 5 | 人物指代是否清楚、表达是否简洁有效 |
| 实际语音自然度与可懂度 | 5 | 实际配音是否自然、清晰、易理解 |
| 交付一致性与可重建性 | 15 | 文件、文本、时间轴和输出是否一致，能否独立重建 |
| 原声保留与旁白开关 | 10 | 原声是否保留，旁白是否可独立开关 |
| 合计 Q | 65 | C = Q ÷ 65，取值0至1 |

## 分数构成算法

1. 沿用独立裁判及程序检查已有的逐项得分率 r（0至1），不改变事实匹配、裁决、题干或冻结答卷。
2. 每项得分 = 本版该项满分 × r。
3. V = 45×r事实 + 35×r状态 + 5×r揭示 + 15×r及时性。
4. Q = 5×r避让 + 10×r对白可懂度 + 10×r音效 + 5×r混音 + 5×r指代 + 5×r语音 + 15×r交付 + 10×r原声开关。
5. C = Q÷65。最终分 S = min(V×C, 已确认失败门槛的最低封顶分)；无失败门槛时上限100。

有效交付八项只汇总为一个系数，不额外加分，也不逐项连乘。某小项零分只减少该系数，不自动使整题归零。若V=0或Q=0，最终分为0。

中间计算保留精度，结果文件保留四位小数，页面显示两位。通过判断依据未舍入结果。达到85分、各项目已评且所有门槛pass才通过。unknown不等于pass或fail，不据此封顶。

待评项不视为已完成或直接判零，使用固定分母分别计算V、Q的上下界，再计算乘积区间。存在待评项时不生成确定总分。

## 硬门槛与判分边界

- 无有效成片或无真实旁白：确认失败时最高20分。
- 暂停、变速、删镜头或插黑场绕过固定时间轴：确认失败时最高20分。
- 关键持有人或转移关系说反并导致错误理解，或提前泄露关键视觉揭示：有明确证据时最高59分。
- 实际声音证明关键对白或音效被严重掩蔽并影响理解：确认失败时最高59分。

事实项评价准确性与重要覆盖，状态项评价关系链，及时性评价有证据的播报延迟，揭示时机评价提前泄露。遗漏不自动等于迟到或提前泄露。同一错误不得重复施加无依据陈述扣分；对不同维度的独立影响必须分别说明。

无固定旁白数量，不要求描述所有细节；保留既有替代覆盖、证据不确定性和声音窗口规则。评价实际交付声音，计划与自查不能替代成片证据。

评分权重为最终版；视觉与文字判定来自GPT-6.1 Sol/high，听觉判定来自Qwen3.8 Omni原生音频评审。参考仍非人工金标准。Astra为50分钟试跑，Luna为60分钟公开协议补跑，两者条件不同，不作同条件因果排名。
