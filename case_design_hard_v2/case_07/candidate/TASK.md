# Case 07｜有干扰人物的可见目标抠像（困难版v2）

为两段真实人物的受控合成镜头制作可复用透明前景。clip_1只保留戴眼镜长发女性；clip_2保留成人与孩子两人。identity_1/2.jpg红框标识初始目标。后面经过的蓝衣胡须男子是干扰人物，移动竖条也是前景遮挡物：全部排除，只保留当帧实际可见目标，不能补画被遮挡的人体。

保留发丝、眼镜、手部、衣物软边及两人间隙；应对目标平移出画、遮挡与重新显露。输入PNG为权威画面，各100帧512×288；25fps是本题播放基准，不代表原拍摄帧率。素材是公开实拍前景/alpha的新组合，非未经处理的原始录像。

交付submission.json，索引rgba_1.zip、rgba_2.zip、dark_1.mp4、light_1.mp4、dark_2.mp4、light_2.mp4和report.json。每个ZIP根目录恰有0000.png–0099.png，均8位RGBA、straight/unassociated alpha，RGB为sRGB，不预乘。透明像素RGB任意。四条预览100帧、25fps、512×288、无音轨，由提交RGBA和input/dark.png、light.png在线性光中合成；输入sRGB先解码、合成后重新编码。可用composite.py复现预览。

report遵循report_schema.json，写处理方法、目标策略、alpha模式、色彩约定与逐帧映射。允许任意本地分割/抠像工具及人工修边；输出不得引用隐藏源alpha或作者参考。

自动60分：格式5、主体内部10、背景5、软边15、遮挡/出画10、运动补偿时序5、前景颜色5、预览复现5。judge40分：身份/可见性15、多背景边缘15、时间连续性10。每段单独检查硬门槛后等权计分，不能用简单镜头掩盖另一段失败。分区定义、锚点和门槛见public_rules.json。正式总分≥80、无硬失败或核心语义失败才通过；judge未完成时总分待定。

真值来自受控合成层。评测会逐帧读RGBA、在多个背景重新合成、验证真实预览，并以固定真值运动场比较时间变化；不是奖励静止遮罩。不同合理修边不要求像素完全相同。来源许可见input/SOURCES.md。
